## 🚀 GitHubでの公開・プレイ方法（完全ステップ）

### Step 1: このZIPファイルを解凍する
ダウンロードした `STUDY_BLOCK_Final.zip` をパソコンで右クリックし、「解凍（すべて展開）」を行ってください。
以下の3つのファイルが入っています：
- `index.html`
- `style.css`
- `script.js`

### Step 2: GitHubにファイルをアップロードする
1. GitHubのリポジトリページ（ `https://github.com/1009yamadaharuto-dot/study-block` ）を開きます。
2. 画面上の **「Add file」** ボタン ➔ **「Upload files」** をクリックします。
3. 解凍した3つのファイル（`index.html`, `style.css`, `script.js`）をまとめてドラッグ＆ドロップします。
4. 画面下の緑色のボタン **「Commit changes」** を押して確定します。

### Step 3: 公開設定（GitHub Pages）
1. リポジトリの上部メニューから **「⚙️ Settings」** を開きます。
2. 左メニューの **「Pages」** をクリックします。
3. Branch を `None` から **`main`** (または `主要`) に切り替えて **「Save」** をクリックします。
